# 世界文化图鉴 · Culture Atlas

一个面向 IB PYP 6 年级学生与合作教师的双语（中英）世界文化对照网页应用。

- 左侧边栏选择国家，底部选择六大文化维度（家庭与关系 / 教育与学习 / 传统与庆典 / 语言与交流 / 信仰与世界观 / 群体与社交生活）
- 主界面左右对照：选定国家 vs 中国（锚点）
- 每个子主题可点击打开弹窗：区域性差异、文化来源、历史演变图、拓展关键词（点击跳转必应搜索）、有趣的小知识
- 每个国家名称可点击打开国家简介弹窗：基本介绍、文化简介、六维文化来源雷达图

**使用方法**：直接打开 `index.html` 即可，无需服务器，断网时除中文字体外功能不受影响。

**在线版本**：https://leinad1357.github.io/culture-atlas/

**维护说明**：应用为单文件（`index.html`），所有内容、数据与样式都在其中。修改后直接提交推送即可更新在线版本。
